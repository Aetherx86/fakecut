# 🎬 FakeCut (페이크컷) — Final Cut Pro 위장 유튜브 플레이어

> **"직장이나 공공장소에서 눈치보지 않고 영상 시청하기"**  
> Apple의 대표 영상 편집 프로그램 **Final Cut Pro X (FCPX)**의 UI 디자인과 동작 방식을 픽셀 단위로 정밀하게 재현하여, 영상 편집 작업을 하는 것처럼 완벽하게 위장해 유튜브를 재생하는 스텔스 뷰어입니다.

---

## ✨ 핵심 기능 (Key Features)

### 1. 🥷 완벽한 Final Cut Pro UI 위장
- **macOS 트래픽 라이트 & 타이틀바**: 창 제어 버튼, 라이브러리 및 프로젝트 경로(`Commercial_Campaign_Final_v3.fcpbundle`).
- **상단 브라우저 & 이벤트 라이브러리**:
  - `01_A-Roll 촬영 원본`, `02_B-Roll 스톡`, `03_음악/SFX`, `04_레퍼런스` 카테고리 구성.
  - **위장 파일명 모드**: 유튜브 영상 제목을 `A001_C024_0424_PRORES_4K.MOV` 같은 실제 카메라 RAW 파일명으로 자동 위장.
  - 필름스트립(Filmstrip), 그리드(Grid) 뷰 및 오디오 파형 바, 해상도/FPS 태그 표시.

### 2. 📺 뷰어 & 실시간 컬러 그레이딩 연동
- **FCP 뷰어 프레임**: 맞춤(Fit), 해상도(3840x2160 | 23.98 fps), 디지털 LCD 타임코드(`00:01:24:18`).
- **실시간 비디오 스코프 (Scopes)**: RGB Parade 및 Waveform 모니터를 실시간으로 띄워 고난도 색보정 작업 중인 것처럼 연출.
- **실시간 CSS 컬러 필터 적용**: 인스펙터의 노출(Exposure), 대비(Contrast), 채도(Saturation), 틴트(Hue Rotate), 블러(Blur) 슬라이더를 조작하면 **재생 중인 유튜브 영상의 색감이 실시간으로 변경**됩니다!

### 3. ⏱ 마그네틱 타임라인 (Magnetic Timeline)
- **실시간 싱크 재생헤드 (Red Playhead)**: 유튜브 영상 재생에 맞춰 빨간색 재생헤드가 타임라인을 가로질러 정밀하게 전진합니다.
- **타임라인 스크러빙 & 탐색**: 타임라인 눈금자나 트랙을 클릭/드래그하면 유튜브 영상이 즉시 해당 위치로 탐색됩니다.
- **오렌지 스키머 (Orange Skimmer)**: 마우스 커서를 올리면 FCP 시그니처 주황색 스키머 라인과 타임코드 툴팁이 따라다닙니다.
- **블레이드 컷 도구 (Blade Tool / 단축키 `B`)**: 칼 도구로 클립을 클릭하면 실제 컷 분할 선이 생깁니다.

### 4. 🚨 긴급 보스키 (Panic Mode / Emergency Render)
- **단축키 `ESC`, `F1`, 또는 상단 [긴급 위장] 버튼 클릭 시**:
  - 즉시 유튜브 영상이 일시정지되고 **음소거**됩니다.
  - 화면 전체에 **"타임라인 미디어 백그라운드 렌더링 (84% 완료 - Apple ProRes 422 HQ)"** 창이 나타나며 고난도 인코딩 작업 중인 것처럼 완벽하게 위장합니다.
  - 다시 `ESC`를 누르면 즉시 편집 뷰로 복귀합니다.

### 5. 📥 자유로운 유튜브 영상 가져오기 (Cmd + I)
- 유튜브 영상 URL(`https://www.youtube.com/watch?v=...`, `youtu.be/...`, 쇼츠 링크 등)을 붙여넣으면 oEmbed 메타데이터를 파싱하여 FCP 라이브러리 클립으로 즉시 등록됩니다.
- 인기 프리셋(코딩 BGM, 도쿄 4K 야경 산책, 지브리 피아노 등) 원클릭 추가 지원.

## ⌨️ 단축키 안내 (Keyboard Shortcuts)

| 단축키 | 기능 설명 |
|---|---|
| `ESC` / `F1` / `` ` `` | **긴급 보스키 (Panic Button)** — 즉시 음소거 및 렌더링 모달로 위장 |
| `Space` | 재생 / 일시정지 |
| `J` / `K` / `L` | 5초 뒤로 / 일시정지 / 5초 앞으로 |
| `←` / `→` | 1초 정밀 탐색 |
| `B` | 블레이드(Blade) 자르기 도구 활성화 |
| `A` | 기본 선택(Select) 도구 활성화 |
| `Cmd + I` (Ctrl + I) | 미디어 가져오기 (Import Media) 창 열기 |
| `녹색 신호등` 버튼 | macOS 전체화면 토글 |

## 🚀 실행 방법

```bash
# 의존성 설치 (최초 1회)
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:5173` 접속 후, 브라우저 전체화면(`Cmd + Ctrl + F` 또는 녹색 신호등 클릭)으로 전환하면 완벽한 macOS Final Cut Pro 애플리케이션으로 작동합니다.
